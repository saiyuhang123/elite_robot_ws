# Inspire 4B4C 夹爪 ROS 2 使用说明

本包为因时 Inspire 4B4C 二指夹爪的 ROS 2 驱动，包含三个包：

- `serial`：串口库
- `service_interfaces`：12 个控制服务定义
- `inspire_gripper`：控制节点（默认打开 `/dev/ttyUSB0`，波特率 115200）

## 1. 编译

在工作区根目录执行（本项目已编译过，改过代码后才需要重新编译）：

```bash
cd /home/nvidia/Documents/elite_robot_ws
colcon build --packages-select serial service_interfaces inspire_gripper
```

## 2. 启动控制节点

终端 1：

```bash
cd /home/nvidia/Documents/elite_robot_ws
source install/setup.bash
ros2 run inspire_gripper Gripper_control_node
```

看到 `serial open success` 表示串口打开成功。

## 3. 查看服务

终端 2：

```bash
cd /home/nvidia/Documents/elite_robot_ws
source install/setup.bash
ros2 service list
```

应能看到 `Setmovetgt`、`Setmovemax`、`Setmovemin`、`Getstatus` 等服务。

## 4. 常用控制命令

默认 `gripper_id = 1`。

### 查询状态（状态码、故障码、温度）

```bash
ros2 service call /Getstatus service_interfaces/srv/Getstatus "{gripper_id: 1, status: 'get_status'}"
```

### 清除故障

```bash
ros2 service call /Setclearerror service_interfaces/srv/Setclearerror "{gripper_id: 1, status: 'set_clearerror'}"
```

### 张开夹爪

速度范围 1~1000：

```bash
ros2 service call /Setmovemax service_interfaces/srv/Setmovemax "{speed: 400, gripper_id: 1, status: 'set_movemax'}"
```

### 闭合夹爪

速度范围 1~1000，力值范围 50~1000：

```bash
ros2 service call /Setmovemin service_interfaces/srv/Setmovemin "{speed: 500, power: 200, gripper_id: 1, status: 'set_movemin'}"
```

### 持续闭合（保持抓取力）

```bash
ros2 service call /Setmoveminhold service_interfaces/srv/Setmoveminhold "{speed: 500, power: 200, gripper_id: 1, status: 'set_moveminhold'}"
```

### 设置开口度

范围 0~1000（500 约等于半开）：

```bash
ros2 service call /Setmovetgt service_interfaces/srv/Setmovetgt "{movetgt: 500, gripper_id: 1, status: 'set_move_tgt'}"
```

### 急停

```bash
ros2 service call /Setestop service_interfaces/srv/Setestop "{gripper_id: 1, status: 'set_estop'}"
```

### 其他服务

- `SetID`：设置夹爪 ID（范围 1~254）
- `Setopenlimit`：设置开口上下限
- `Setparam`：参数固化
- `Getopenlimit`：读取开口上下限
- `Getcopen`：读取当前开口度

## 5. 注意事项

1. 串口默认写死在源码 `src/inspire_gripper/src/Gripper_control.cpp` 的 `/dev/ttyUSB0`，若夹爪在其他串口，需修改该行后重新编译：

```bash
colcon build --packages-select inspire_gripper
```

2. `status` 字符串必须带引号。
3. 服务类型是 `service_interfaces/srv/Setmovetgt` 这类名字（注意是 `SetID`，不是 `SetpID`）。
4. 完整命令清单见 `src/ros2_4B4C使用方法.txt`。
