# 打磨系统启动命令

> 参数配置：`src/elite_polish_app/config/polish_params.yaml`（改参数不用重编译，重启 launch 生效）

> **2026-08-02 力控模式改造**：接触后启用控制器内建力控（`startForceMode`），
> z 向恒力由机器人控制器闭环完成，不再用 404 的 ±0.5mm bang-bang 位置修正。
> 改动涉及三个包：`eli_common_interface`（新增 ForceMode.srv）、
> `eli_cs_robot_driver`（硬件接口暴露 `/force_mode_server/set_force_mode` 服务）、
> `elite_polish_app`（接触后调用）。**必须全部重新编译并重启机械臂驱动**，否则打磨会中止。

## 一、启动顺序（4 个终端）

```bash
# 终端1: 机械臂驱动
cd ~/Documents/elite_robot_ws
source install/setup.bash
# 正式调度由启动面板管理，不单独启动 RViz
ros2 launch my_elite_robot_cell_control start_robot.launch.py headless_mode:=true launch_rviz:=false
```

```bash
# 终端2: 检查并激活轨迹控制器（）
source /opt/ros/humble/setup.bash
ros2 control list_controllers | grep scaled
# 显示 inactive 则执行:
ros2 control set_controller_state scaled_joint_trajectory_controller active
```

```bash
# 终端3: 深度相机（仅视觉流程需要；跳过视觉的空跑不用开）
ros2 launch percipio_camera percipio_camera.launch.py
```

```bash
# 终端4: 打磨系统
cd ~/Documents/elite_robot_ws
source install/setup.bash
ros2 launch elite_polish_app elite_polish.launch.py
```

**启动自检**：
- 状态机日志无 `Couldn't find chain` FATAL；
- 去皮值 `device bias wrench` 应在 1~3N 量级（启动时机械臂必须静止、打磨头无接触）；
- 桥接节点无 `goal was REJECTED`；
- 驱动日志出现 `Force mode service ready: /force_mode_server/set_force_mode`。
- 视觉成功时出现 `[plane fit] OK`，并检查 `RMS`、`angle_to_world_x` 均未超过配置上限；
- 第一次启用法向跟随后先空跑，确认 `normal_base` 朝世界 X+/工件内部。

可选验证：
```bash
ros2 service list | grep force_mode     # 应出现 /force_mode_server/set_force_mode
ros2 service call /force_mode_server/set_force_mode eli_common_interface/srv/ForceMode "{enable: false}"
```

## 力控模式相关参数（polish_params.yaml）

| 参数 | 默认 | 说明 |
|---|---|---|
| `use_force_mode` | true | true=startForceMode 内建力控；false=回退旧 bang-bang（调试用） |
| `force_mode_wrench_z` | +3.0 | SDK 内部施力目标；当前 z+ = 拟合工件法向（约为世界 x+） |
| `force_mode_sensor_target_fz` | -1.5 | 应用补偿/去皮后的实际反作用力目标；与 SDK 内部读数实测相差约 1.1N |
| `force_mode_z_vel_limit` | 0.0005 | 首次验证最大调整速度(m/s)，确认方向后最多逐步升到 0.001 |
| `contact_fz_threshold` | -1.0 | 预备姿态局部归零后的反作用力阈值，连续 8 帧才确认接触 |
| `force_mode_max_axial_deviation` | 0.040 | 力控实际位姿相对接触偏置后名义路径的最大轴向偏移(m) |
| `force_mode_abort_fz` | -5.0 | 20 帧平均力的持续过力阈值(N) |
| `force_mode_hard_abort_fz` | -15.0 | 单帧瞬时过力硬保护(N) |
| `force_mode_abort_confirm_time` | 0.12 | 平均力越过 -5 N 的持续确认时间(s) |
| `polish_tool_spinup_time` | 1.0 | 打磨头开启后原地稳压时间(s) |

⚠ 接触后先发送当前位置保持目标并等待 action 完成，再开启力控。实测反作用力需在 -1.5±0.6N 内连续稳定
0.5s，才允许开启打磨头；IO 开启确认后再原地稳压 1.0s 才开始切向轨迹。单帧力超过 -15N、20帧平均力超过 -5N 并持续 0.12s、失去接触超过 2s 或轴向偏差超过 40mm 时会自动退出。
退刀先沿拟合工件法向反向后退 30mm，再竖直抬升，不再执行原来的 y+ 100mm 侧移。

## 二、运行动作

### 命令 0：回 Home2
```bash
ros2 topic pub --once /elite_forceapp_cmd std_msgs/msg/Int32 "data: 0"
```

### 命令 3：完整自动流程

机械臂到拍摄位 → 深度识别 → 接触 → 打磨 → 回 Home2。终态结果码：

- `104`：成功并已回 Home2
- `204`：失败，已安全收尾并回 Home2
- `205`：已取消，已安全收尾并回 Home2

安全取消使用命令 5：

```bash
ros2 topic pub --once /elite_forceapp_cmd std_msgs/msg/Int32 "data: 5"
```

### 跳过视觉测打磨（空跑，debug_skip_force_contact: true 时）

```bash
# 1. 注入参考系（空闲状态下注入；轨迹区在 polishBase 前方）
ros2 topic pub --once /elite_vision_pose_broadcaster/pose geometry_msgs/msg/PoseStamped "{
  pose: {
    position: {x: -0.019042, y: -0.118052, z: -0.067389},
    orientation: {x: 0.399683, y: 0.034057, z: 0.912134, w: -0.084295}
  }
}"
# 确认日志出现: frame APPLIED

# 2. 发打磨命令
ros2 topic pub --once /elite_forceapp_cmd std_msgs/msg/Int32 "data: 4"
```

### 命令 3：深度定位 + 自动接打磨
```bash
ros2 topic pub --once /elite_forceapp_cmd std_msgs/msg/Int32 "data: 3"
```
当前默认先用深度图自动拟合地面并提取最大矩形板面，失败才回退 cluster；depth 和
cluster 都失败时停止，不使用旧固定框。视觉完成后会**自动进入打磨流程**，发之前
确认：深度掩膜和尺寸门检查正常、速度调低、手放急停上。

调试查看：

```bash
rqt_image_view /elite_polish/depth_board_mask
ros2 topic echo /elite_polish/depth_board_info
```

### 手动打磨机 IO 测试
```bash
# 通过应用节点测试（内部转换为 fun=2, pin=7）
ros2 topic pub --once /elite_forceapp_cmd std_msgs/msg/Int32 "data: 52"  # 开
ros2 topic pub --once /elite_forceapp_cmd std_msgs/msg/Int32 "data: 51"  # 关

# 直接调用驱动 IO 服务
ros2 service call /io_and_status_controller/set_io eli_common_interface/srv/SetIO "{fun: 2, pin: 7, state: true}"
ros2 service call /io_and_status_controller/set_io eli_common_interface/srv/SetIO "{fun: 2, pin: 7, state: false}"
```

自动打磨中，力控验证通过后的子步骤 403 自动开启打磨头，完成或异常退出的子步骤 405 自动关闭。

## 五、安全要点

1. 启动打磨系统时机械臂**静止、打磨头无接触**（力去皮需要）；
2. 测试全程**低速**（速度比例 10~20%）、手放急停上；
3. 403/405 步会通断 DO0，未接线验证前打磨机**不接电**；
4. 任何异常：急停 → 看日志 sub_step 停在哪 → 查 `docs/联调记录_2026-07-27.md`。
