# 打磨系统启动命令

> 参数配置：`src/elite_polish_app/config/polish_params.yaml`（改参数不用重编译，重启 launch 生效）

## 一、启动顺序（4 个终端）

```bash
# 终端1: 机械臂驱动
cd ~/Documents/elite_robot_ws
source install/setup.bash
ros2 launch my_elite_robot_cell_control start_robot.launch.py headless_mode:=true launch_rviz:=false
```

```bash
# 终端2: 检查并激活轨迹控制器（每次重启驱动后必做！）
source /opt/ros/humble/setup.bash
ros2 control list_controllers | grep scaled
# 显示 inactive 则执行:
ros2 control set_controller_state scaled_joint_trajectory_controller active
```

```bash
# 终端3: 深度相机（仅视觉流程需要；跳过视觉的空跑不用开）
ros2 launch realsense2_camera rs_launch.py pointcloud.enable:=true camera_namespace:=camera
```

```bash
# 终端4: 打磨系统
cd ~/Documents/elite_robot_ws
source install/setup.bash
ros2 launch elite_polish_app elite_polish.launch.py
```

**启动自检**：
- 状态机日志无 `Couldn't find chain` FATAL；
- 去皮值 `device bias wrench` 应在 1~3N 量级（启动时机械臂必须静止、打磨头无接触）；
- 桥接节点无 `goal was REJECTED`。

## 二、运行动作

### 命令 0：回 Home
```bash
ros2 topic pub --once /elite_forceapp_cmd std_msgs/msg/Int32 "data: 0"
```

### 跳过视觉测打磨（空跑，debug_skip_force_contact: true 时）

```bash
# 1. 注入参考系（空闲状态下注入；轨迹区在 polishBase 前方）
ros2 topic pub --once /elite_vision_pose_broadcaster/pose geometry_msgs/msg/PoseStamped "{
  pose: {
    position: {x: -0.019042, y: -0.118052, z: -0.067389},
    orientation: {x: 0.399683, y: 0.034057, z: 0.912134, w: -0.084295}
  }
}"
# 确认日志出现: frame APPLIED

# 2. 发打磨命令
ros2 topic pub --once /elite_forceapp_cmd std_msgs/msg/Int32 "data: 4"
```

### 命令 3：视觉定位 + 自动接打磨（需相机和标定好的裁剪盒）
```bash
ros2 topic pub --once /elite_forceapp_cmd std_msgs/msg/Int32 "data: 3"
```
⚠ 视觉完成后会**自动进入打磨流程**，发之前确认：裁剪盒已标定、速度调低、手放急停上。

### 手动打磨机 IO 测试
```bash
ros2 topic pub --once /elite_forceapp_cmd std_msgs/msg/Int32 "data: 52"  # 开 (DO0=1)
ros2 topic pub --once /elite_forceapp_cmd std_msgs/msg/Int32 "data: 51"  # 关 (DO0=0)
```

## 三、视觉标定工具（biaoding/）

```bash
# 差分标定（同一拍照位拍两张: 空治具 → 有工件）
ros2 topic pub --once /elite_vision_job_cmd std_msgs/msg/Int32 "data: 1"
cp /tmp/base.pcd /tmp/empty.pcd
ros2 topic pub --once /elite_vision_job_cmd std_msgs/msg/Int32 "data: 1"
cp /tmp/base.pcd /tmp/with_part.pcd
python3 biaoding/pcd_diff.py            # 输出工件包围盒 → 填 yaml 的 target_box_*

# 辅助工具
python3 biaoding/pcd_box_tool.py --hist # 点云密度普查（找工件位置）
python3 biaoding/pcd_cluster.py         # 连通域聚类（区分工件/噪声）
python3 biaoding/grinder_tip.py         # 打磨头尖端坐标（验证手眼/量点）
```

## 四、常用检查

```bash
ros2 topic echo /force_torque_sensor_broadcaster/wrench --once   # 原始力数据
ros2 topic echo /ys_contact_fts_broadcaster/wrench --once        # 去皮后接触力
ros2 run tf2_ros tf2_echo cs66_base_link cs66_tool0              # 法兰位姿(URDF FK)
ros2 topic hz /camera/camera/depth/color/points                  # 点云频率
```

## 五、安全要点

1. 启动打磨系统时机械臂**静止、打磨头无接触**（力去皮需要）；
2. 测试全程**低速**（速度比例 10~20%）、手放急停上；
3. 403/405 步会通断 DO0，未接线验证前打磨机**不接电**；
4. 任何异常：急停 → 看日志 sub_step 停在哪 → 查 `docs/联调记录_2026-07-27.md`。
