## 第 1 步：补完冒烟测试（10 分钟）

**目的**：确认"状态机 → 桥接 → 控制器"链路在控制器激活后可用。

```bash
# 终端1: 驱动（每次重启驱动后必须检查控制器状态）
cd ~/Documents/elite_robot_ws && source install/setup.bash
ros2 launch my_elite_robot_cell_control start_robot.launch.py headless_mode:=true launch_rviz:=false

# 终端2: 检查并激活控制器
ros2 control list_controllers | grep scaled
# 若显示 inactive:
ros2 control set_controller_state scaled_joint_trajectory_controller active

# 终端3: 打磨系统
ros2 launch elite_polish_app elite_polish.launch.py

# 终端4: 发命令 0（回 Home，当前为占位姿态，注意周围环境）
ros2 topic pub --once /elite_forceapp_cmd std_msgs/msg/Int32 "data: 0"
```

**完成效果**：机械臂走到 Home 姿态；桥接节点日志无 `goal was REJECTED`；状态机无 `Couldn't find chain` FATAL。

## 第 2 步：示教三个姿态（1~2 小时）【已完成 2026-07-26】

> 已填入并编译：`ys_home_q_` = `ys_cameraCapture_q_` = (8.2, -93.6, -110.2, 57.4, 91.7, 91.6)°；
> `ys_polishBase_q_` = (0.2583, -1.7438, -1.5621, 0.7505, 1.5043, 1.5330) rad。
> 注意：polishBase 为弧度制直接赋值（无 deg→rad 转换），home/camera 为角度制带转换，改动时别混。

| 姿态 | 示教原则 |
|---|---|
| `ys_home_q_` | 安全停靠位，不碰任何东西 |
| `ys_cameraCapture_q_` | 相机正对工件，距离 0.4~0.8m，视野完整罩住工件 |
| `ys_polishBase_q_` | 打磨头离工件 10~30cm 的过渡位（不用贴很近），到工件路径无遮挡，**关节构型与打磨姿态接近**（它是轨迹起点 IK 的种子角） |

操作：示教器移动机械臂 → 读取六个关节角（角度制）→ 发给开发协助者，或自行填入
`src/elite_polish_app/src/ysURForceAppControl.cpp` 的 `initDataQ()`（约 207-227 行，已标 `TODO: RE-TEACH`）。

```bash
colcon build --packages-select elite_polish_app && source install/setup.bash
```

**完成效果**：命令 0 走到新 Home；后续命令 3/4 使用新姿态。

## 第 3 步：裁剪盒标定（半天）

**目的**：让视觉能从点云里圈出工件并算出参考系。工具：`biaoding/pcd_box_tool.py`（离线模拟 CropBox）。

### 3.1 拍一帧点云

```bash
# 工件放治具上，机械臂在拍照位（示教好后可用命令3走位，或手动拖过去）
ros2 topic pub --once /elite_vision_job_cmd std_msgs/msg/Int32 "data: 1"
ls -l /tmp/base.pcd   # 确认时间戳是刚拍的
```

⚠ 拍照后工件和拍照位都不能动。

### 3.2 大盒（`pclCalcTransform.hpp` `getTargetCloud`）

```bash
python3 biaoding/pcd_box_tool.py 0.3 -0.8 0.0 1.0 -0.2 0.6   # 粗估范围起试
```

逐步收紧，直到：**盒内点全是工件**（无桌面/台架/机械臂本体），四壁比工件宽 2~3cm 余量。
判断依据：盒内 min/max ≈ 工件实际尺寸；某方向贴盒壁说明切到工件要放宽。

### 3.3 三个测点盒（`getPlaneFrame`）

在大盒圈出的工件平面上挑三个位置：原点 O、沿 x 距 O 约 10cm 的 X 点、沿 z 距 O 约 10cm 的 Y 点
（参照 ysrob 原值相对布局）。每盒 x/z 方向 ±5mm，y 方向贯通覆盖工件：

```bash
python3 biaoding/pcd_box_tool.py 0.60 -0.60 0.30 0.61 -0.40 0.31   # 逐个验证
```

每个盒内至少几百点、质心在盒中心附近。

### 3.4 先填前三组，跑一遍生成平面系点云

填入 `pclCalcTransform.hpp` → `colcon build --packages-select elite_polish_app` → 重新拍照。
检查中间产物（保存在节点工作目录，通常 `~/.ros/`）：

```bash
ls -l ~/.ros/plane_trans.pcd ~/.ros/curve_plane.pcd
```

### 3.5 圆弧盒（`getCurveCloud`，坐标在平面系下！）

```bash
python3 biaoding/pcd_box_tool.py ~/.ros/plane_trans.pcd          # 看整体范围
python3 biaoding/pcd_box_tool.py ~/.ros/plane_trans.pcd -0.25 0.24 -0.095 0.25 0.54 -0.045
```

合格标准：盒内只剩圆弧/边缘特征的点。同时重验 `getCurveFrame` 常数（0.9306/1.89539，
隐含 ysrob 打磨机长度，你的机器 tool z 伸出 18cm，大概率要改）。

### 3.6 终验

四组全部填入 → 编译 → 重拍 → 看视觉节点终端各层点数：

```
base cloud size / target cloud size / tmp cloud size(×3) / curve box cloud size
```

**完成效果**：各层点数非零且合理；视觉输出位姿（`/elite_vision_pose_broadcaster/pose`）落在工件上
（可用 `grinder_tip.py` 盒子法抽查）。

## 第 4 步：力传感器与工艺参数（1~2 小时）

1. **负载识别**：【已完成 2026-07-26】质量 1.478 kg，质心 (-56.32, 19.36, -19.86) mm（含打磨机+相机）；
2. **重力补偿参数**：【已填入并编译】`ys_tool_gravity_` = (10.7654, -0.1738, -9.6917) N
   （= 1.478×9.8×世界系向下在 base 系的方向），`ys_tool_gcenter_` = (-0.05632, 0.01936, -0.01986) m。
   **待验证**：重启节点（静止无接触完成去皮）后，大幅变换机械臂姿态，接触力读数应保持在 0 附近
   （漂移 < 1~2N）；漂移大说明示教器质心坐标系定义与 tool0 不一致，需调整符号/轴序；
3. **退刀轨迹重调**：【已修改 2026-07-26】`polish_goBackHome` 原硬编码"base z 拉到 0.4m"
   已改为"世界系竖直抬刀 0.15m + base y 侧移 0.1m"（抬刀方向 = `(-0.7431, 0.0120, 0.6691)`）。
   抬刀高度 `lift_height` 在 `ysURForceAppControl.cpp` 约 966 行，空跑时观察是否合适再调；
4. **力控参数先保守**：`target_fz_` ≈ 5N，`adjust_dz_` 小值，死区保持 3N。

**完成效果**：机械臂大姿态变换后力读数漂移小（重力补偿生效）；参数就绪。

## 第 5 步：空跑联调（半天，打磨机不接电）

```bash
# 发命令 3：视觉定位，完成后会自动链入命令 4 打磨流程！
ros2 topic pub --once /elite_forceapp_cmd std_msgs/msg/Int32 "data: 3"
```

⚠ **安全准备**（发命令前）：polishBase 已示教；速度比例调低（10~20%）；手放急停上；
打磨机**不接电**（IO 通断不影响观察）。

**完成效果**（依次观察）：

1. 走到拍照位 → 视觉解算 → 输出工件位姿；
2. 走到 polishBase → 走到轨迹起点上方预备点；
3. 沿 tool z 缓慢下压，接触力到达阈值后停（看力读数）；
4. 之字形打磨走位（打磨机不转）；
5. 退刀 → 回 Home → 发布完成结果。

任何一步异常：看桥接有无 REJECTED、状态机日志的子步骤号（3xx/4xx）停在哪。

## 第 6 步：真磨

1. 打磨机电源控制线接**控制柜 DO0**；
2. 单独验证 IO：`ros2 service call /io_and_status_controller/set_io ...`（或在空跑时观察 DO0 通断）；
3. 低速度、小目标力试磨 → 观察打磨纹路和力稳定性；
4. 逐步调 `target_fz_`、`adjust_dz_`、速度比例到工艺要求。

**完成效果**：完整打磨一件工件，接触力稳定在 `target_fz_` ±3N 死区内，轨迹覆盖整个弧面。
