# 三种末端执行器控制命令

本文整理当前工作区中三种末端执行器的启动和测试命令：

- LinkerHand O6 灵巧手
- Inspire 4B4C 二指夹爪
- 柔触三指气动夹爪

## 一、公共环境

每个终端先执行：

```bash
cd ~/Documents/elite_robot_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
```

如果包还没有编译，执行：

```bash
colcon build --packages-select \
  linker_hand_ros2_sdk \
  serial service_interfaces inspire_gripper \
  gripper_control --symlink-install
source install/setup.bash
```

同一时间只启动一种夹爪控制节点，避免多个设备节点互相干扰。

## 二、LinkerHand O6 灵巧手

### 2.1 开启 CAN

```bash
sudo ip link set can2 up type can bitrate 1000000
ip link show can2
```

### 2.2 普通 Launch 启动

当前 launch 默认配置为：右手、O6、CAN `can2`、关闭压感读取。

```bash
ros2 launch linker_hand_ros2_sdk linker_hand.launch.py
```

如果需要开启传感器检测，可使用：

```bash
ros2 run linker_hand_ros2_sdk linker_hand_sdk --ros-args \
  -p hand_type:=right \
  -p hand_joint:=O6 \
  -p is_touch:=true \
  -p can:=can2 \
  -p modbus:=None
```

### 2.3 手指张开、半闭合、闭合

张开：

```bash
ros2 topic pub --once /cb_right_hand_control_cmd sensor_msgs/msg/JointState \
"{name: [], position: [255, 255, 255, 255, 255, 255], velocity: [], effort: []}"
```

半闭合成笼：

```bash
ros2 topic pub --once /cb_right_hand_control_cmd sensor_msgs/msg/JointState \
"{name: [], position: [180, 25, 180, 180, 180, 180], velocity: [], effort: []}"
```

闭合：

```bash
ros2 topic pub --once /cb_right_hand_control_cmd sensor_msgs/msg/JointState \
"{name: [], position: [0, 5, 50, 50, 50, 50], velocity: [], effort: []}"
```

### 2.4 设置速度和最大扭矩限制

设置速度等级为 50：

```bash
ros2 topic pub --once /cb_right_hand_setting_cmd std_msgs/msg/String \
"{data: '{\"setting_cmd\": \"set_speed\", \"params\": {\"hand_type\": \"right\", \"speed\": [50, 50, 50, 50, 50, 50]}}'}"
```

设置最大扭矩限制为 30：

```bash
ros2 topic pub --once /cb_right_hand_setting_cmd std_msgs/msg/String \
"{data: '{\"setting_cmd\": \"set_max_torque_limits\", \"params\": {\"hand_type\": \"right\", \"torque\": [30, 30, 30, 30, 30, 30]}}'}"
```

这里的最大扭矩限制不是接触力闭环控制。

### 2.5 查看状态

```bash
ros2 topic echo /cb_right_hand_state
ros2 topic echo /cb_right_hand_info
```

## 三、Inspire 4B4C 二指夹爪

默认串口为 `/dev/ttyGripper`（即原来的 `/dev/ttyCH341USB1`，由 udev 按物理端口固定），默认夹爪 ID 为 `1`。

### 3.1 启动控制节点

```bash
ros2 run inspire_gripper Gripper_control_node
```

看到 `serial open success` 表示串口打开成功。

查看服务：

```bash
ros2 service list | grep -E "Set|Get"
```

### 3.2 查询状态和清除故障

查询状态：

```bash
ros2 service call /Getstatus service_interfaces/srv/Getstatus \
"{gripper_id: 1, status: 'get_status'}"
```

清除故障：

```bash
ros2 service call /Setclearerror service_interfaces/srv/Setclearerror \
"{gripper_id: 1, status: 'set_clearerror'}"
```

### 3.3 张开、闭合和保持夹持

张开：

```bash
ros2 service call /Setmovemax service_interfaces/srv/Setmovemax \
"{speed: 400, gripper_id: 1, status: 'set_movemax'}"
```

闭合：

```bash
ros2 service call /Setmovemin service_interfaces/srv/Setmovemin \
"{speed: 500, power: 200, gripper_id: 1, status: 'set_movemin'}"
```

闭合并保持夹持力：

```bash
ros2 service call /Setmoveminhold service_interfaces/srv/Setmoveminhold \
"{speed: 500, power: 200, gripper_id: 1, status: 'set_moveminhold'}"
```

设置开口度，范围 `0~1000`，约 `500` 为半开：

```bash
ros2 service call /Setmovetgt service_interfaces/srv/Setmovetgt \
"{movetgt: 500, gripper_id: 1, status: 'set_move_tgt'}"
```

急停：

```bash
ros2 service call /Setestop service_interfaces/srv/Setestop \
"{gripper_id: 1, status: 'set_estop'}"
```

### 3.4 接入视觉抓取

先启动二指控制节点，再启动抓取程序：

```bash
cd ~/Documents/elite_robot_ws/biaoding
python3 yolo_grasp.py --gripper two_finger
```

二指一体化 Launch：

```bash
ros2 launch ~/Documents/elite_robot_ws/biaoding/yolo_grasp_two_finger.launch.py
```

## 四、柔触三指气动夹爪

柔触夹爪也是 ROS 2 服务形式：

```text
ROS 2 服务 /gripper_command
        ↓
gripper_server
        ↓ Modbus TCP
柔触夹爪控制器
```

默认设备地址为 `192.168.1.194:502`。

### 4.1 启动 ROS 服务节点

```bash
ros2 launch gripper_control soft_touch.launch.py
```

上面的 launch 已配置设备地址 `192.168.1.194`、端口 `502`。如果只想直接运行节点，也可以使用：

```bash
ros2 run gripper_control gripper_server
```

查看服务和气压话题：

```bash
ros2 service list | grep gripper
ros2 topic echo /gripper_pressure
ros2 topic echo /gripper_pressure_info
```

### 4.2 柔触控制命令

启动正压，手指闭合：

```bash
ros2 service call /gripper_command gripper_control/srv/GripperCommand \
"{command: 0, value: 0, slave_id: 1}"
```

释放正压：

```bash
ros2 service call /gripper_command gripper_control/srv/GripperCommand \
"{command: 1, value: 0, slave_id: 1}"
```

启动负压，手指张开：

```bash
ros2 service call /gripper_command gripper_control/srv/GripperCommand \
"{command: 2, value: 0, slave_id: 1}"
```

释放负压：

```bash
ros2 service call /gripper_command gripper_control/srv/GripperCommand \
"{command: 3, value: 0, slave_id: 1}"
```

设置正压上限，单位 kPa：

```bash
ros2 service call /gripper_command gripper_control/srv/GripperCommand \
"{command: 4, value: 150, slave_id: 1}"
```

设置负压值，通常使用负数：

```bash
ros2 service call /gripper_command gripper_control/srv/GripperCommand \
"{command: 5, value: -50, slave_id: 1}"
```

读取正压反馈：

```bash
ros2 service call /gripper_command gripper_control/srv/GripperCommand \
"{command: 6, value: 0, slave_id: 1}"
```

读取负压反馈：

```bash
ros2 service call /gripper_command gripper_control/srv/GripperCommand \
"{command: 7, value: 0, slave_id: 1}"
```

### 4.3 接入视觉抓取

先启动 `gripper_server`，再运行：

```bash
cd ~/Documents/elite_robot_ws/biaoding
python3 yolo_grasp.py --gripper soft_touch
```

## 五、视觉抓取通用服务

运行 `yolo_grasp.py` 后，可以用以下服务控制当前夹爪：

```bash
# 张开
ros2 service call /yolo_grasp/open std_srvs/srv/Trigger

# 闭合
ros2 service call /yolo_grasp/close std_srvs/srv/Trigger

# 执行一次抓取
ros2 service call /yolo_grasp/grasp std_srvs/srv/Trigger

# 查看目标状态
ros2 service call /yolo_grasp/status std_srvs/srv/Trigger
```

测试时请先空载张开，再使用半闭合或低速闭合，确认方向和开口姿态正确后再抓取物体。
